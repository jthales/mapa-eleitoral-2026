# Frontend — Mapa Eleitoral 2026

Angular standalone, TypeScript, SCSS e Vitest. Instale com `npm ci`; rode `npm start` com a API em localhost:5080. Dashboard em http://127.0.0.1:4200/dashboard.

`npm run build` produz dist/frontend/browser; `npm test` executa a suíte sem watch.

Requisitos, configuração real/mock, limitações e comandos completos no [README da raiz](../README.md). Antes de alterar, ler [AGENTS.md](../AGENTS.md) e [estado atual](../docs/current-status.md).
